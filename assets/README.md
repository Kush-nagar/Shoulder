# Brand asset workspace

`shoulder-icon-system.png` is the uploaded visual reference sheet. It is included so the implementation team can compare the geometry, lockups, and color examples.

It is not a production logo source. Before the frontend is visually complete, obtain/export the approved vector files listed in `../docs/08-brand.md`. Keep the custom wordmark as paths, not live text, and visually verify every favicon/app-icon raster at its actual display size.

Do not auto-trace this PNG and treat the result as final artwork.
