# API contracts

`openapi.json` comes from FastAPI. `api.d.ts` is generated by openapi-typescript.
Never edit either by hand. From the repository root, run:

```powershell
.\.tools\uv.exe run --locked python -m scripts.export_openapi
npm.cmd exec --yes --package=pnpm@11.25.0 -- pnpm contracts
```

The Task 1 health shell has no API consumer or product data types.
